# callrec Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, open-source macOS CLI that silently records iPhone Continuity / FaceTime phone calls on a Mac (far side + own mic), one file per call, and transcribes each call locally with whisper.cpp into a timestamped Markdown file.

**Architecture:** A Swift Package executable `callrec` with three concerns kept in separate files: (1) capture, using a Core Audio **process tap** (`CATapDescription` + `AudioHardwareCreateProcessTap` + private aggregate device) for the far-side audio and `AVAudioEngine` for the mic, written as two WAV files then merged with ffmpeg; (2) a **watcher** that polls Core Audio process objects once per second and starts/stops a recording when the call daemon begins/ends producing output; (3) a **transcriber** that shells out to `whisper-cli` (whisper.cpp, Metal) with a Hinglish glossary prompt and writes `.md`. Everything lands in `~/CallRecordings/YYYY-MM-DD/HH-MM-SS.{m4a,md}`. A launchd agent keeps `callrec watch` running. `install.sh` fetches a prebuilt arm64 binary from GitHub Releases (or builds from source), installs `whisper-cpp` + `ffmpeg` via Homebrew, downloads the model, and loads the launchd agent.

**Tech Stack:** Swift 5.9+ (SwiftPM, macOS 14 deployment target), CoreAudio (process taps, macOS 14.2+), AVFoundation (mic), whisper.cpp via Homebrew `whisper-cpp` (`whisper-cli`), ffmpeg via Homebrew, bash install script, GitHub Actions for release binary. Reference implementation for the tap code: https://github.com/insidegui/AudioCap (MIT) — read `ProcessTap.swift` and `AudioRecordingPermission.swift` there before writing Task 3.

**Spec:** This plan is its own spec. Product decisions (from Devansh, 2026-09-18): free; no cloud; no announcement to the other party; per-call auto-record with a manual session fallback; local whisper.cpp large-v3-turbo; Hinglish (English with Hindi glue words); output must be readable by a non-technical partner (Anurag) who installs with one command and has no Claude.

## Global Constraints

- Platform: macOS 14.2 or newer, Apple Silicon only. `install.sh` must check both and exit with a plain-English message otherwise.
- No paid dependencies, no cloud calls, no telemetry. Transcription runs on-device.
- Never write outside `~/CallRecordings/`, `~/.callrec/`, `~/Library/LaunchAgents/com.blaxify.callrec.plist`, and `/usr/local/bin/callrec` (or `~/.callrec/bin/callrec` if not writable).
- Audio format on disk: `.m4a` AAC 64 kbps mono 16 kHz for storage; a temporary 16 kHz mono 16-bit WAV is what whisper reads and is deleted after transcription.
- File naming: `~/CallRecordings/YYYY-MM-DD/HH-MM-SS.m4a` and `HH-MM-SS.md`, local time, 24h. Zero-padded.
- All user-facing text in plain English, no jargon. Errors say what to do next.
- Repo: public, MIT, `github.com/DDOS44/callrec`. Commit after every task with a conventional-commit message. Do not commit `~/.callrec` contents, models, or recordings.
- Tests: `swift test` for pure logic (paths, silence splitting, config, markdown rendering). Audio capture and whisper are verified by manual steps written into the task; do not mock Core Audio.
- The builder runs on Devansh's Mac (macOS 26.5, arm64, Swift 6.3, Homebrew, ffmpeg present, `whisper-cpp` NOT yet installed, gh logged in as DDOS44). Homebrew installs require Devansh's approval once; ask before the first `brew install`.

// Shell.swift
import Foundation
enum Shell {
    @discardableResult
    static func run(_ cmd: String, _ args: [String], timeout: TimeInterval = 600) throws -> (status: Int32, stdout: String, stderr: String) {
        let p = Process(); p.executableURL = URL(fileURLWithPath: cmd); p.arguments = args
        let out = Pipe(), err = Pipe(); p.standardOutput = out; p.standardError = err
        try p.run()
        let deadline = Date().addingTimeInterval(timeout)
        while p.isRunning && Date() < deadline { Thread.sleep(forTimeInterval: 0.05) }
        if p.isRunning { p.terminate(); throw NSError(domain: "callrec", code: 124, userInfo: [NSLocalizedDescriptionKey: "\(cmd) timed out after \(Int(timeout))s"]) }
        let o = String(decoding: out.fileHandleForReading.readDataToEndOfFile(), as: UTF8.self)
        let e = String(decoding: err.fileHandleForReading.readDataToEndOfFile(), as: UTF8.self)
        return (p.terminationStatus, o, e)
    }
    static func which(_ name: String) -> String? {
        for dir in ["/opt/homebrew/bin", "/usr/local/bin", "/usr/bin", "/bin"] {
            let p = dir + "/" + name; if FileManager.default.isExecutableFile(atPath: p) { return p }
        }
        return nil
    }
}

- [ ] **Step 3: Process object snapshot**

```swift
// AudioProcessWatcher.swift
import CoreAudio
import Foundation

struct AudioProcessInfo { let objectID: AudioObjectID; let pid: pid_t; let bundleID: String; let isRunningOutput: Bool; let isRunningInput: Bool }

enum AudioProcessWatcher {
    static func snapshot() throws -> [AudioProcessInfo] {
        var addr = AudioObjectPropertyAddress(mSelector: kAudioHardwarePropertyProcessObjectList,
                                              mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var size: UInt32 = 0
        try check(AudioObjectGetPropertyDataSize(AudioObjectID(kAudioObjectSystemObject), &addr, 0, nil, &size))
        var ids = [AudioObjectID](repeating: 0, count: Int(size) / MemoryLayout<AudioObjectID>.size)
        try check(AudioObjectGetPropertyData(AudioObjectID(kAudioObjectSystemObject), &addr, 0, nil, &size, &ids))
        return ids.map { id in
            AudioProcessInfo(objectID: id,
                             pid: (try? readPID(id)) ?? -1,
                             bundleID: (try? readString(id, kAudioProcessPropertyBundleID)) ?? "",
                             isRunningOutput: (try? readBool(id, kAudioProcessPropertyIsRunningOutput)) ?? false,
                             isRunningInput: (try? readBool(id, kAudioProcessPropertyIsRunningInput)) ?? false)
        }
    }
    private static func readPID(_ id: AudioObjectID) throws -> pid_t {
        var addr = AudioObjectPropertyAddress(mSelector: kAudioProcessPropertyPID, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var v: pid_t = 0; var size = UInt32(MemoryLayout<pid_t>.size)
        try check(AudioObjectGetPropertyData(id, &addr, 0, nil, &size, &v)); return v
    }
    private static func readBool(_ id: AudioObjectID, _ sel: AudioObjectPropertySelector) throws -> Bool {
        var addr = AudioObjectPropertyAddress(mSelector: sel, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var v: UInt32 = 0; var size = UInt32(MemoryLayout<UInt32>.size)
        try check(AudioObjectGetPropertyData(id, &addr, 0, nil, &size, &v)); return v != 0
    }
    private static func readString(_ id: AudioObjectID, _ sel: AudioObjectPropertySelector) throws -> String {
        var addr = AudioObjectPropertyAddress(mSelector: sel, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var v: Unmanaged<CFString>? = nil; var size = UInt32(MemoryLayout<Unmanaged<CFString>?>.size)
        try check(AudioObjectGetPropertyData(id, &addr, 0, nil, &size, &v))
        return v?.takeRetainedValue() as String? ?? ""
    }
    static func check(_ s: OSStatus) throws {
        if s != noErr { throw NSError(domain: "CoreAudio", code: Int(s), userInfo: [NSLocalizedDescriptionKey: "CoreAudio error \(s)"]) }
    }
}
```

func usage() -> Never { print("usage: callrec <probe|record|watch|transcribe|status|session>"); exit(2) }

            print("[\(Date())]"); active.sorted().forEach { print("  ", $0) }
            last = active
        }

    }

import Foundation
struct RecordingPaths {
    let dir: URL; let base: String
    var m4a: URL { dir.appendingPathComponent(base + ".m4a") }
    var md: URL { dir.appendingPathComponent(base + ".md") }
    var farWav: URL { dir.appendingPathComponent(base + ".far.wav") }
    var micWav: URL { dir.appendingPathComponent(base + ".mic.wav") }
    var mixWav: URL { dir.appendingPathComponent(base + ".mix.wav") }
}
enum Paths {
    static var root: URL = FileManager.default.homeDirectoryForCurrentUser.appendingPathComponent("CallRecordings")
    static func forCall(at date: Date, root: URL = Paths.root) -> RecordingPaths {
        let day = DateFormatter(); day.dateFormat = "yyyy-MM-dd"
        let time = DateFormatter(); time.dateFormat = "HH-mm-ss"
        return RecordingPaths(dir: root.appendingPathComponent(day.string(from: date)), base: time.string(from: date))
    }
    static func ensureDir(_ url: URL) throws { try FileManager.default.createDirectory(at: url, withIntermediateDirectories: true) }
}

### Task 3: ProcessTap — far-side audio to WAV

**Files:**
- Create: `Sources/callrec/ProcessTap.swift`
- Modify: `Sources/callrec/main.swift` (wire `tap-test` from Task 0 to this class)

**Interfaces:**
- Produces: `final class ProcessTap { enum Mode { case globalExcluding([AudioObjectID]) }; init(mode: Mode) throws; func start(onBuffer: @escaping (UnsafePointer<AudioBufferList>, UInt32) -> Void) throws; func stop(); var format: AudioStreamBasicDescription { get } }` and `final class WavWriter { init(url: URL, format: AudioStreamBasicDescription) throws; func write(_ abl: UnsafePointer<AudioBufferList>, frames: UInt32); func close() }` (built on `ExtAudioFile`, writes 16-bit PCM WAV at the tap's sample rate).

- [ ] **Step 1: Implement ProcessTap** following AudioCap's `ProcessTap.swift` exactly in structure:
  1. `let desc = CATapDescription(stereoGlobalTapButExcludeProcesses: excluded)`; `desc.uuid = UUID()`; `desc.muteBehavior = .unmuted` (the user must keep hearing the call).
  2. `AudioHardwareCreateProcessTap(desc, &tapID)`.
  3. Read the tap's format: `kAudioTapPropertyFormat` on `tapID` → `AudioStreamBasicDescription`.
  4. Read the default output device UID (`kAudioHardwarePropertyDefaultOutputDevice` → `kAudioDevicePropertyDeviceUID`).
  5. Create a private aggregate device: dictionary with `kAudioAggregateDeviceNameKey: "callrec-tap"`, `kAudioAggregateDeviceUIDKey: UUID string`, `kAudioAggregateDeviceMainSubDeviceKey: outputUID`, `kAudioAggregateDeviceIsPrivateKey: true`, `kAudioAggregateDeviceIsStackedKey: false`, `kAudioAggregateDeviceTapAutoStartKey: true`, `kAudioAggregateDeviceSubDeviceListKey: [[kAudioSubDeviceUIDKey: outputUID]]`, `kAudioAggregateDeviceTapListKey: [[kAudioSubTapDriftCompensationKey: true, kAudioSubTapUIDKey: desc.uuid.uuidString]]`. `AudioHardwareCreateAggregateDevice(dict, &aggID)`.
  6. `AudioDeviceCreateIOProcIDWithBlock(&procID, aggID, nil) { _, inInputData, _, _, _ in onBuffer(inInputData, frames) }` then `AudioDeviceStart(aggID, procID)`.
  7. `stop()`: `AudioDeviceStop`, `AudioDeviceDestroyIOProcID`, `AudioHardwareDestroyAggregateDevice`, `AudioHardwareDestroyProcessTap`. Also run all of these in `deinit` guarded by a `started` flag.
  Frames per buffer come from `inInputData.pointee.mBuffers.0.mDataByteSize / format.mBytesPerFrame`.

- [ ] **Step 2: Implement WavWriter** with `ExtAudioFileCreateWithURL(url, kAudioFileWAVEType, &outFormat, nil, AudioFileFlags.eraseFile.rawValue, &ref)` where `outFormat` = 16-bit signed int PCM, same sample rate and channel count as the tap; `ExtAudioFileSetProperty(ref, kExtAudioFileProperty_ClientDataFormat, ...)` = the tap's float format; `write` calls `ExtAudioFileWrite(ref, frames, abl)`; `close` calls `ExtAudioFileDispose`.

### Task 5: CallRecorder — run both, merge with ffmpeg, produce m4a + mix wav

- Consumes: `ProcessTap`, `WavWriter`, `MicRecorder`, `Paths`, `Config`, `Shell`.
- Produces: `final class CallRecorder { let paths: RecordingPaths; init(config: Config, startedAt: Date = Date()) throws; func start() throws; func stop() throws -> RecordingResult }`, `struct RecordingResult { let paths: RecordingPaths; let seconds: Double; let kept: Bool }`.

- [ ] **Step 1: Implement** `start()`: `try Paths.ensureDir(paths.dir)`; create tap + `WavWriter(url: paths.farWav)`; `MicRecorder(url: paths.micWav)`; start both; remember `startedAt`.
  `stop()`: stop both; `seconds = Date().timeIntervalSince(startedAt)`; if `seconds < config.minCallSeconds` → delete both wavs, return `kept: false`. Else run ffmpeg twice:
  ```
  ffmpeg -y -i far.wav -i mic.wav -filter_complex "[0:a][1:a]amix=inputs=2:duration=longest:normalize=0,aresample=16000" -ac 1 -ar 16000 -c:a pcm_s16le mix.wav
  ffmpeg -y -i mix.wav -c:a aac -b:a 64k m4a
  ```
  via `Shell.run(Shell.which("ffmpeg")!, [...])`, then delete `far.wav` and `mic.wav`. Keep `mix.wav` (Task 6 consumes and deletes it). If ffmpeg is missing, throw with message: "ffmpeg not found. Run: brew install ffmpeg".

import Foundation
struct Segment { let start: Double; let end: Double; let text: String }
enum Markdown {
    static func render(date: Date, seconds: Double, audioName: String, segments: [Segment]) -> String {
        let f = DateFormatter(); f.dateFormat = "yyyy-MM-dd HH:mm"
        let m = Int(seconds) / 60, s = Int(seconds) % 60
        var out = "# Call \(f.string(from: date))\n\n- duration: \(m)m \(String(format: "%02d", s))s\n- audio: \(audioName)\n- outcome: \n- who picked up: \n\n## Transcript\n\n"
        for seg in segments {
            let mm = Int(seg.start) / 60, ss = Int(seg.start) % 60
            out += "[\(String(format: "%02d:%02d", mm, ss))] \(seg.text.trimmingCharacters(in: .whitespaces))\n"
        }
        out += "\n## Notes\n\n- what they said that wasn't in the flow: \n"
        return out
    }
}

```swift
enum SilenceSplitter {
    static func spans(rms: [Float], frameSeconds: Double, threshold: Float, minGapSeconds: Double, minSpanSeconds: Double) -> [(start: Double, end: Double)] {
        var out: [(Double, Double)] = []
        var spanStart: Int? = nil; var lastLoud: Int = 0
        let gapFrames = Int(minGapSeconds / frameSeconds)
        for (i, v) in rms.enumerated() {
            if v >= threshold {
                if spanStart == nil { spanStart = i }
                lastLoud = i
            } else if let s = spanStart, i - lastLoud >= gapFrames {
                out.append((Double(s) * frameSeconds, Double(lastLoud + 1) * frameSeconds)); spanStart = nil
            }
        }
        if let s = spanStart { out.append((Double(s) * frameSeconds, Double(lastLoud + 1) * frameSeconds)) }
        return out.filter { $0.1 - $0.0 >= minSpanSeconds }.map { (start: $0.0, end: $0.1) }
    }
}
```
